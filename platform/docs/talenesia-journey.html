02

Where the Student ID actually flows

The single most consequential mechanism in this journey: a persistent Student ID is created at Phase 1 and correctly threads through the financial chain (Sales Order → invoice → certificate). It breaks down structurally once per-batch spreadsheets take over from Phase 6 onward — not because the ID stops existing, but because nothing forces whoever creates that batch's sheet to include it.
